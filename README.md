# Amazon Prime Video Tableau Dashboard

## Project Overview
This Tableau dashboard analyzes Amazon Prime Video movies and TV shows using interactive visualizations.

The dashboard helps understand:
- Content distribution by country
- Top genres
- Ratings analysis
- Release year trends
- Movies vs TV Shows comparison
- Cast and description details

---

## Dataset Used
- amazon_prime_titles.csv

The dataset contains information about:
- Show titles
- Genres
- Ratings
- Release years
- Duration
- Countries
- Cast details
- Show type (Movie / TV Show)
